# LandingDemo

Демонстрационный лендинг вымышленной компании по ремонту квартир «Квадро».

Откройте `index.html` двойным щелчком в современном браузере. Для переноса скопируйте всю папку проекта вместе с `assets`, `styles.css` и `script.js`.

Страница использует локальные изображения, шрифт и JavaScript. Калькулятор рассчитывает примерную стоимость по учебным расценкам. Форма обрабатывает введённый пример только в памяти страницы и показывает демонстрационное сообщение.

12 ноября 2026 года проверены калькулятор, форма, галерея, мобильное меню и вёрстка на восьми ширинах от 320 до 1440 пикселей через локальный HTTP-сервер. Исправлена валидация знака `+` в телефоне. Проверки синтаксиса JavaScript и ссылок на локальные ресурсы прошли.

Прямое открытие через `file://`, автономный просмотр после отключения сети и перенос папки ожидают отдельной проверки. Встроенный браузер для проверки разрешает только HTTP и HTTPS. Подробные результаты находятся в плане проекта.
